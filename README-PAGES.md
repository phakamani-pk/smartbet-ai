# SmartBet AI — GitHub Pages Preview

This repository is prepared with a static front-end preview that can be served by GitHub Pages from the `docs/` folder.

## Files

- `docs/index.html` — main dashboard shell
- `docs/styles.css` — styling and layout
- `docs/app.js` — sample analytics data and interactions
- `docs/.nojekyll` — disables Jekyll processing
- `.github/workflows/pages.yml` — GitHub Actions deployment workflow

## Publish

1. Push this repository to GitHub.
2. Open the repository in GitHub.
3. Go to Settings → Pages.
4. Set Source to GitHub Actions.
5. The workflow will deploy automatically.

## Local preview

Open `docs/index.html` directly in a browser, or serve the folder with any static file server.
